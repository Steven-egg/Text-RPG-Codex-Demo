# Asset Production Inventory v0.1

Purpose: Visual asset list for the playable RPG. This document defines the image generation targets, prompt briefs, and mapping rules for the Border/Fire and Ice regions. It is the single source of truth for visual asset IDs and alignment during the production phase.

## 核心生成與對齊規則 (Visual Mapping Rules)

1. **顯示名稱為視覺真理來源 (Display Name as Visual SSOT)**：
   在開發早期，運行期代碼中的 `id`（例如 `mon_ice_bilge_crab`、`mon_ice_salt_wisp`）多為佔位符。後續所有圖像生成與視覺設計，**必須以運行期資料中定義的「顯示名稱（Display Name）」為視覺核心主體**，而非字面上的英文 ID。
2. **圖像類型定義 (Image Types)**：
   * `scene`：區域大圖、城鎮背景、設施背景、副本探索場景、戰鬥背景（均採用 16:9 或適合 UI 呈現之比例，像素藝術風格）。
   * `creature`：普通怪物、首領（採用角色/怪物立繪，去背或純色背景，像素藝術風格）。
3. **優先級 (Priority)**：
   * `High`：冰雪區域（Ice），首個面向生產的區域。
   * `Low / Audit`：邊境與火焰路線（Border / Fire），僅作為對齊與架構基準，暫不優先生成。
