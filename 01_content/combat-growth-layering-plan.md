# 戰鬥成長系統分層設計草案

本文件記錄目前「職業玩法定位先行，屬性系統暫緩」的設計結論。它是 markdown-only 規劃文件，不代表任何 runtime 功能已啟用。

本輪不修改 Python、runtime data、schema、save/state 或 engine；不新增八元素、不新增完整屬性克制、不新增精神屬性、不開放正式職業特化、轉職或聖物系統。

## 1. 核心結論

目前應先穩定四職業玩法語言，再決定屬性、轉職、聖物等較大的成長系統如何承接。

完整屬性系統暫緩，原因如下：

- 現況實際只薄薄使用火、冰與少量狀態語意。
- 若擴大到八元素，需要先有世界觀、章節、迷宮、印記與怪物架構。
- 怪物與關卡不能為了湊屬性而硬塞弱點。
- 屬性克制會同時牽動技能、裝備、怪物、關卡、UI、schema 與戰鬥公式。
- 目前不應大改 combat formula，也不應新增 save/state 或 schema 欄位。

短期方向是把火、冰視為局部特色，而不是正式元素矩陣：

| 屬性 | 暫定用途 | 邊界 |
|---|---|---|
| 火 | 焦石礦坑、灰燼裂谷、火傷害、火抗裝備、火之印記線索 | 保留局部火傷與火抗，不擴成完整火系流派 |
| 冰 | 冰針術與個別技能語意，例如對火屬敵人有效 | 不新增冰抗裝備、冰迷宮或冰系狀態 |

## 2. 五個系統的分層關係

| 層級 | 定位 | 近期狀態 |
|---|---|---|
| 職業玩法定位 | 定義四職業在普通攻擊、技能、裝備、被動想像上的差異 | 最高優先，先做 markdown-only |
| 職業特化 preview | 用少量可見預告承接職業方向，不啟用效果 | 已有 preview-only，可同步文案 |
| 裝備與副武器效果 | 用單一裝備驗證職業特色，例如影袖副刃 | 可做最小 MVP，但需下一輪明確施工 |
| 屬性世界觀架構 | 定義元素、章節、迷宮、印記與怪物主題的關係 | 可 markdown-only，暫不 runtime |
| 完整屬性克制 | 八元素、抗性表、弱點 UI、怪物/裝備/技能全面接入 | 必須延後 |

盜賊影袖副刃普通攻擊追擊歸類在「裝備與副武器效果」層，也可視為職業特化 preview 的第一個玩法實例。它不是正式職業特化系統，不需要 `offhand`、save/state 或 schema 擴充作為前置。

## 3. 四職業玩法定位

| 職業 | 暫定方向 | 不做的事 |
|---|---|---|
| 法師 | 強魔法、弱物理；依賴 MP、魔法書、魔攻裝備與未來元素適性 | 暫不要求完整元素系統 |
| 盜賊 | 強物理、技能較少；靠先手、暴擊、裝備效果、副武器追擊、流血、標記、中毒、破甲等形成特色 | 不把盜賊做成第二個法師，不讓普通攻擊直接變 2 倍輸出 |
| 戰士 | 穩定物理職；偏能力強化、破甲、反擊、防禦姿態、盾/武器特效與站場穩定度 | 不以單純高倍率傷害作為唯一特色 |
| 牧師 | 續戰型魔法職；偏持續魔法傷害、治療、護盾、自身續戰、淨化與未來聖屬性方向 | 不等同於法師，不走元素爆發主軸 |

## 4. 屬性與狀態邊界

魔法屬性與物理效果應分層處理：

| 類型 | 例子 | 設計意義 | 施工判斷 |
|---|---|---|---|
| 魔法/世界觀屬性 | 火、冰、雷、聖、暗 | 連接迷宮、印記、怪物、生態與魔法書 | 先 markdown-only，暫不做完整矩陣 |
| 物理/戰術效果 | 流血、破甲、標記、中毒 | 讓裝備、副武器、道具與職業玩法產生差異 | 可做單一低風險 MVP |

近期 preview 可優先碰低風險追擊、破甲、標記等單點效果。DOT、完整異常抗性、全元素弱點 UI、全職業元素適性、完整屬性抗性表都應延後。

目前不新增精神屬性。若未來要讓精神影響魔法傷害、魔法防禦、治療量或異常抗性，必須先評估 `get_stats()`、裝備 stat key、schema、validation、save compatibility 與平衡風險。近期仍沿用既有 `attack + magic_attack`、`defense`、固定治療量與既有 buff/debuff。

## 5. 系統優先順序

1. 職業玩法定位文件。
2. 盜賊影袖副刃普通攻擊追擊 MVP。
3. 職業特化 preview 文案同步。
4. 屬性世界觀架構 markdown-only MVP。
5. 完整八元素與屬性克制系統。

## 6. 可做、延後與禁止施工

現在可以做 markdown-only：

- 職業玩法定位草案。
- 五系統分層草案。
- 火、冰暫定定位。
- snapshot 與 handoff 結論同步。
- 影袖副刃下一輪 MVP 規格。

近期可做最小 MVP：

- 影袖副刃普通攻擊低倍率追擊。
- 單一副武器效果 preview。
- 職業特化文案同步。
- 極小範圍的物理效果 prototype。

必須延後：

- 八元素。
- 完整屬性抗性表。
- 正式職業特化選擇。
- 完整轉職。
- 完整聖物。
- 精神屬性。
- 第二元素迷宮。
- 完整 DOT 或異常抗性框架。

目前禁止施工：

- 修改 Python、runtime data、schema、save/state、engine。
- 新增八元素或完整屬性克制表。
- 新增精神屬性。
- 新增完整職業特化系統。
- 新增完整轉職系統。
- 新增完整聖物系統。
- 新增 `offhand` slot。
- 大改 combat formula。

## 7. 下一輪建議

下一輪適合回到「盜賊影袖副刃普通攻擊追擊最小 MVP」。

施工前應先鎖定：

- 只在普通攻擊觸發，不在技能攻擊觸發。
- 只在裝備 `armor_rogue_sleeve_blade` 時觸發。
- 追擊為低倍率物理傷害，不讓總輸出變成單純 2 倍。
- 不新增 `offhand`、schema、save/state 或新裝備欄位。
- 擊殺、經驗、金幣、掉落結算不得重複。

若下一輪進入施工，驗收至少包含：裝備時觸發、未裝備不觸發、其他職業不觸發、技能不觸發、結算不重複，以及 `run_checks.bat` 通過。
