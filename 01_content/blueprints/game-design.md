# 《元素迷宮：邊境冒險者》v1 設計文件

版本：v1.0 垂直切片  
語言：繁體中文  
類型：輕冒險文字 RPG  
核心形式：單人多職業、步數事件式迷宮、回合制文字選單戰鬥  
交付目標：提供可直接實作的系統規格、內容表、平衡基準與驗收條件。

## 1. 遊戲定位

《元素迷宮：邊境冒險者》是一款不以沉重劇情為主軸的文字冒險 RPG。玩家的樂趣來自進入未知迷宮、遭遇戰鬥、帶回素材、回到城鎮整備，並透過裝備、魔法書、合成與工會任務逐步突破更高階的迷宮。

### 1.1 核心循環

```text
進入迷宮探索
→ 遭遇戰鬥與事件
→ 獲得素材、金幣、經驗、裝備
→ 返回邊境城鎮艾爾姆
→ 工匠街購買/強化裝備
→ 星燈魔法商店學習技能
→ 米菈合成屋製作對策道具
→ 工會交付任務並解鎖下一目標
→ 挑戰更高階迷宮
```

### 1.2 v1 成功標準

- 玩家能完成一次完整的「探索、戰鬥、掉落、回城整備、強化、再挑戰」循環。
- 玩家能感受到不同店鋪分工：武器、防具、飾品補給、合成、魔法書。
- 玩家能透過魔法書永久學會技能，且技能會影響戰鬥選擇。
- 玩家能理解焦石礦坑需要火抗、防禦技能或補給準備。
- 玩家擊敗 Boss `山寨頭目葛倫` 後，取得 `血跡地圖`，自然引出第二幕元素迷宮。

### 1.3 v1 不包含

- 不實作小隊制。
- 不實作永久死亡。
- 不開放正式轉職，只在轉職神殿展示條件與未來目標。
- 不做大量分支劇情，劇情以階段目標和解鎖提示推進。

### 5.5 副武器效果方向

副武器不應只是第二把主武器，也不應讓普通攻擊直接變成 2 倍輸出。中後期的副武器定位應是「效果載體」：讓盜賊或未來刺客路線依敵人、迷宮與資源狀態選擇不同副武器。

短期仍不新增 `offhand` slot。第一批原型可沿用既有 `head` slot 的「副武器」語意，例如 `armor_rogue_sleeve_blade`，先驗證玩法方向，再決定是否需要正式雙持欄位、schema 或 save/state 擴充。

| 類型 | 核心效果 | 例子 | 設計定位 | MVP 注意 |
|---|---|---|---|---|
| 魔法類型副武器 | 帶屬性的持續傷害或元素追擊 | 火焰灼燒、冰霜凍傷、毒素侵蝕 | 讓副武器成為元素對策或長線傷害來源 | 應等元素與持續傷害框架更清楚後再施工 |
| 物理效果副武器 | 附加戰術狀態或短期弱化 | 流血、破甲、標記、中毒 | 讓刺客依敵人防禦、血量或迷宮特性選擇武器 | 第一個原型應只做單一低風險效果 |

後續若要實作，應先選一個副武器與一個效果做最小原型，不一次完成完整狀態系統。職業特化可在未來承接副武器玩法，但不應作為下一個副武器 MVP 的前置條件。

職業玩法、屬性暫緩與副武器追擊的分層結論另見 `01_content/archive/combat-growth-layering-plan.md`。

## 7. 戰鬥系統

### 7.1 基本指令

```text
[攻擊] [防禦] [技能] [道具] [逃跑]
```

| 指令 | 效果 |
|---|---|
| 攻擊 | 使用武器進行普通攻擊。 |
| 防禦 | 本回合受到傷害 -40%，若已學守護符文則防禦時額外回復 MP 2。 |
| 技能 | 使用職業技能或魔法書技能。 |
| 道具 | 使用藥水、卷軸、破甲釘等。 |
| 逃跑 | 依敏捷與迷宮難度判定，Boss 戰不可逃跑。 |

### 7.2 行動順序

```text
行動值 = 敏捷 + random(1, 10)
行動值高者先行動
```

若雙方行動值相同，玩家優先。盜賊通常能先手，Boss 擁有固定先制技能時例外。

### 7.3 命中

```text
命中率 = 攻擊方命中 - 目標敏捷 * 0.5 + 技能命中修正
最低命中率 = 65%
最高命中率 = 98%
```

### 7.4 傷害公式

```text
基礎傷害 = max(1, 攻擊方攻擊 * 技能倍率 - 目標防禦 * 0.6)
最終傷害 = 基礎傷害 * 屬性倍率 * 暴擊倍率 * 防禦修正 * 抗性修正
```

| 修正 | 數值 |
|---|---|
| 普通攻擊技能倍率 | 1.0 |
| 小傷害技能倍率 | 1.25-1.35 |
| Boss 強攻倍率 | 1.4 |
| 暴擊倍率 | 1.5 |
| 防禦指令修正 | 0.6 |
| 火抗 -25% | 抗性修正 0.75 |

### 7.5 屬性相剋

v1 使用簡化屬性，完整元素系統留給第二幕。

| 攻擊屬性 | 目標屬性 | 倍率 |
|---|---|---:|
| 冰 | 火 | 1.2 |
| 火 | 青苔/自然 | 1.1 |
| 物理 | 無 | 1.0 |
| 火 | 火 | 0.75 |

|---|---|---|---|

### 7.7 戰敗

戰敗時玩家被工會救回城鎮：

- 保留本趟取得經驗的 50%。
- 失去本趟取得金幣的 30%。
- 保留本趟取得素材的 70%，向下取整。
- 不會永久失去裝備。

目的：失敗有代價，但不會摧毀探索意願。

## 13. 第一版流程腳本

### 13.1 開局 15 分鐘目標

1. 玩家建立角色並選職業。
2. 在冒險者工會接任務「冒險者登記」。
3. 旅人小鋪購買小藥水或集中滴露。
4. 進入青苔洞窟。
5. 遭遇 2-4 場戰鬥，取得素材。
6. 回城交付「洞窟採集」。
7. 解鎖合成屋與逃脫卷軸。

### 13.2 中段 30-60 分鐘目標

1. 玩家刷青苔洞窟 2-3 趟。
2. 購買第一件明顯升級裝備或一本魔法書。
3. 完成「魔晶研究」或「焦石偵查」。
4. 進入焦石礦坑，感受到火屬性壓力。
5. 回城準備抗火斗篷、暖石墜、守護符文或補給。

### 13.3 v1 結尾目標

1. 玩家挑戰焦石礦坑深處。
2. 與山寨頭目葛倫戰鬥。
3. 擊敗 Boss 後取得血跡地圖與火之印記碎片。
4. 工會會長迴避血跡地圖來源，留下第二幕伏筆。
5. 轉職神殿出現新對話，提示火印碎片仍需查閱；不提前開放正式轉職或完整火印。

## 17. 設計假設

- 工匠採專門店分工，不採職業專屬店或等級分店。
- 魔法書是永久技能學習道具，不是消耗品或裝備。
- 本文件原本描述 v1 範圍；目前 runtime 已追加灰燼裂谷、燼印深窟、灰燼守衛與燼印鎮衛。最新可玩狀態以 `README.md` 與 runtime data 為準。
- 戰鬥以清楚、可預測、可準備為主，不追求複雜隱藏公式。
- 所有素材至少有一個明確用途：合成、任務、解鎖或魔法書學習。
- 劇情文字以短句與階段目標為主，不以長篇對話推進。
