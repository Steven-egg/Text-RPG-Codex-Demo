## 1. 任務一：邊境的無色旅人 (The Colorless Traveler)

*   **任務 ID**：`quest_register_and_gathering` (對應 `quest_cave_gathering`)
*   **建議等級**：Lv. 1 - Lv. 3
*   **涉及地城**：青苔洞窟 (Moss Cave, 共 12 步)
*   **解鎖設施**：米菈合成屋 (Mira's Synthesis)

### A. 任務起點：公會登記與「無色徽記」
主角為了尋找導師 Eldrin 的線索，踏入奧克哈芬的冒險者公會。

*   **場景**：公會大廳。壁爐內柴火噼啪作響，窗外暴雨如注。接待員諾亞正無聊地翻看著名冊。
*   **對話劇本**：
    ```
    [主角走到櫃檯前，將一枚陳舊的、沒有任何元素光芒的鐵質徽記放在桌上。]

    諾亞：（抬頭，原本公式化的微笑在看到徽記時瞬間凝固，他迅速用衣袖蓋住徽記，低聲警告）
    「……收起來。如果你不想在半夜被教會的淨化騎士吊死在鎮口的話，孩子。」

    主角：（警惕地縮回手）
    「你認得它？這是我的導師艾爾德林留下的。」

    諾亞：（眼神閃過一絲痛苦與懷念，隨即恢復冷靜）
    「我不認得。我只知道十年前帶著這玩意的人，把半個邊境攪得天翻地覆，然後像煙一樣消失了。聽著，我會發給你一張公會的『見習徽章』作為掩護。在這裡，低調才能活得久。」

    [諾亞遞過名冊。]

    諾亞：
    「選一個你在地底下防身的行當吧（選擇職業）。選好了，就幫公會跑個腿。最近青苔洞窟傳來一陣不該有的焦味，去採集一些『青苔纖維』與『破裂石片』回來。記住，活著回來才有資格提問題。」
    ```

### B. 地城事件：青苔洞窟的異常
*   **第 6 步事件：焦黑的植被**
    *   *文字描述*：你注意到洞窟兩側原本濕潤的青苔已經碳化變黑，散發著刺鼻的煤煙味。岩壁上有被高溫炙烤留下的熔融痕跡，這絕非普通的自然現象。
*   **第 10 步事件：冒險者的遺骸（取得文檔）**
    *   *文字描述*：在岩石縫隙中，你發現了一具焦黑的骸骨。骸骨的背包已經被燒穿，但裡面有一封被羊皮紙包裹的信件，字跡因高溫而有些扭曲。
    *   **【Lore 文檔：焦黑的信】**：
        > 「……水井在變乾，地底的熱氣一天比一天重。那幫山賊（葛倫的手下）在礦坑深處架設了奇怪的管線。他們在抽地脈的血！如果公會再不派人來，火山會把奧克哈芬埋了……」
*   **第 12 步 Boss 戰**：擊敗**裂石小魔像** (mon_cracked_golem)，回收「破裂石片」。

### C. 任務交付：米菈合成屋解鎖
*   **對話劇本**：
    ```
    主角：（將素材遞交給諾亞，並出示焦黑的信）

    諾亞：（看著信件，臉色陰沉）
    「葛倫這傢伙……看來他已經不滿足於搶劫商旅，開始對地底的古代遺跡動手了。拉比！你過來看看這石片。」

    鐵匠拉比：（從隔壁工作坊走過來，粗大的手指捏起石片，嗅了嗅）
    「呸！這上面有古代熔爐的萃取渣味。那群山賊肯定在用逆向設備抽取火元素。主角，你這身衣服在熱氣底下撐不了多久，去找米菈那丫頭，她知道怎麼處理這些纖維。」

    米菈：（在櫃檯旁熱情地招手）
    「哈囉！新來的冒險者！哇，你帶回來的青苔纖維活性很好呢！來，我教你怎麼用這些纖維和石片合成『新手防護藥劑』。在我的合成屋裡，只要素材夠，什麼神奇的東西都做得出來哦！」
    ```

## 2. 任務二：焦石之底的狂徒 (The Scorched Mine)

*   **任務 ID**：`quest_boss_glen`
*   **建議等級**：Lv. 4 - Lv. 6
*   **涉及地城**：焦石礦坑 (Scorched Mine, Steps 1-18)
*   **解鎖設施**：工坊裝備強化、魔晶商店部分折扣

### A. 任務發布
為了阻止山賊過載礦坑地脈，諾亞委託主角前往焦石礦坑討伐山賊頭目葛倫。

*   **對話劇本**：
    ```
    諾亞：
    「葛倫的人馬把礦坑圍了起來，連工匠們都無法進去採礦。據說他們挖到了地脈封印的外圍。主角，去解決葛倫，奪回被他搶走的礦山控制權。這是不僅是為了小鎮，也是為了查清那些逆向設備的來源。」
    ```

### B. 地城事件與 Boss 戰 (第 18 步)
*   **場景**：焦石礦坑深處。一台巨大的黃銅活塞泵浦正瘋狂抽動，滾燙的蒸汽四溢。葛倫一隻手提著巨大的燃燒戰斧，另一隻手握著一塊散發赤紅光芒的碎片。
*   **對話劇本**：
    ```
    葛倫：（狂笑，臉上滿是煤煙與汗水）
    「哈哈哈哈！聽聽這機器的轟鳴！公會那群膽小鬼把這東西當成惡魔的封印，但在老子眼裡，這就是源源不絕的黃金！這斧頭只要吸飽了這塊碎片的火毒，連城門都能一斧劈開！」

    主角：
    「停下機器，葛倫！火山地脈已經失衡了！」

    葛倫：
    「少跟老子說教，公會的小狗！等老子把這幾塊『火印碎片』全融進武器裡，這整個邊境就是老子說了算！既然來了，就給我的寶貝斧頭當祭品吧！」

    [戰鬥開始：Boss 葛倫 (boss_glen)]
    ```

### C. 戰後演出與廢墟中的地圖
*   **對話劇本**：
    ```
    [葛倫倒在地上，口吐鮮血，但他臉上依然掛著瘋狂的笑容。]

    葛倫：
    「咳……哈哈……你以為你贏了？這機器已經過載了……誰也拿不走火印……一起死吧！」

    [葛倫拼死拉動黃銅泵浦的過載閥門。整座礦坑開始劇烈搖晃，滾燙的熔岩從石縫中噴湧而出，落石將葛倫的身體掩埋。主角在千鈞一髮之際，搶下了葛倫掉落的一卷羊皮紙，狼狽地往回跑。]

    [獲得關鍵道具：key_blood_map (血跡地圖)]
    ```

## 3. 任務三：灰底的陰謀與熱阻對策 (The Ash Conspiracy)

*   **任務 ID**：`quest_ash_ravine`
*   **建議等級**：Lv. 7 - Lv. 9
*   **涉及地城**：灰燼裂谷 (Ash Ravine, Steps 1-18, 次要地城 B)
*   **解鎖機制**：合成「抗火斗篷」與「耐熱中藥水」，主地城 Phase 2 解鎖

### A. 劇情轉折：地圖與教會的影子
主角將血跡地圖帶回公會。

*   **對話劇本**：
    ```
    諾亞：（看著血跡地圖上用暗紅色液體繪製的線索，眉頭緊鎖）
    「這地圖上的符文……不是山賊畫得出來的。這是神殿內部的地脈密碼。賽恩，你認得這個嗎？」

    祭司賽恩：（從神殿走來，看著地圖，閉上雙眼默哀）
    「神聖光芒啊……這是『灰燼裂谷』的古代祭壇座標。那是封印的第二層鎖。葛倫背後有教會聖城的『極端派』在提供技術支援。他們想逼出地脈中的元素結晶作為軍事能源，完全不在乎邊境居民的死活。」

    主角：
    「我們必須阻止他們。」

    賽恩：
    「裂谷深處已經被高溫熔岩吞噬，且有古代守護者守衛。沒有足夠的耐熱手段，你進去只會被瞬間化為灰燼。主角，你必須去裂谷外圍收集『精煉火石』與『熔岩碎片』，我們需要製作抗熱裝備。」
    ```

### B. 灰燼裂谷探索與守門 Boss
*   **地城目標**：擊敗**灰燼守衛** (boss_ash_guardian)，取得「精煉火石」與「熔岩碎片」。
*   **探索事件**：在裂谷祭壇前，主角的「無色徽記」發熱，腦海中閃過導師艾爾德林與一名身穿高階教會長袍者爭執的模糊幻象。

### C. 回城合成與補給線升級
*   **對話劇本**：
    ```
    鐵匠拉比：
    「很好，有了這些精煉火石，我可以用工坊的鼓風爐將你的防具進行『耐熱鋼化』。主角，把你的護甲拿過來！」

    魔法屋伊芙：（雙手抱胸，語氣雖然刻薄但眼神認真）
    「光有笨重的鐵甲有什麼用？沒腦子的戰士。拿著這張『抗火斗篷』配方。米菈，用熔岩碎片和青苔纖維作為基底，配合我的冰霜魔力微粒，調配出『耐熱中藥水』。動作快，那個大鐵疙瘩在等著他呢。」

    米菈：
    「交給我吧！主角，這藥水喝下去雖然苦得像啃樹皮，但能讓你在熔岩深處自由呼吸半個時辰！一定要記得喝哦！」
    ```

## 4. 任務四：燼之封印的終息 (The Cinder Seal)

*   **任務 ID**：`quest_cinder_seal`
*   **建議等級**：Lv. 9 - Lv. 11
*   **涉及地城**：燼印深窟 (Cinder Seal Depths, Scorched Mine Steps 19-36)
*   **解鎖機制**：回收三枚「火之印記碎片」，通關 Act 1

### A. 深入熔岩神殿
主角服用「耐熱中藥水」並裝備「抗火斗篷」，回到了崩塌的焦石礦坑，融化了冷凝的熔岩壁，深入到了未被地圖記載的古代地下神殿——「燼印深窟」。

*   **場景變化**：原本粗糙的礦道變為由巨大黑色玄武岩與紅色能量管道構成的古代過濾器管道。兩側的小怪變為狂暴的**餘燼潛獵者**，雙眼燃燒著失去理智的紅光。

### B. 關底 Boss 戰：燼印鎮衛 (Steps 36)
*   **場景**：熔岩湖中央的巨大懸浮石台。三枚「火印碎片」被吸附在一個古代十字架上，源源不絕地將狂暴的能量注入一尊高達三米的鋼鐵重裝魔像中。
*   **對話劇本**：
    ```
    [魔像雙眼亮起刺眼的紅光，巨劍在石地上劃出刺耳的火花。]

    系統語音：（古代機械合成音，冰冷而無情感）
    「檢測到未授權虛無雜質……地脈淨化程序啟動……抹殺所有非元素生物……」

    [戰鬥開始：Boss 燼印鎮衛 (boss_cinder_seal_sentinel)]
    ```

### C. 淨化與回收印記
*   **劇情演出**：
    ```
    [燼印鎮衛龐大的軀體支撐不住，跪倒在地，身上的赤紅管道逐一熄滅。懸浮在空中的三枚火印碎片失去依附，開始瘋狂震動，即將引發二次爆炸。]

    [主角走上前，深吸一口氣，伸出雙手。體內的「無色徽記」爆發出空白的光芒，形成一股柔和的引力，將狂暴的火元素波動吸引並壓制下來。]

    [三枚火印碎片的光芒漸漸平息，化為溫和的暗紅色晶體，輕輕落在主角的手掌中。熔岩湖的暴動停止了，空氣中的高熱開始退去。]
    ```

## 5. 終章：啟程與北方的共鳴 (Departure & Northern Resonance)

*   **任務 ID**：`epilogue_to_galeport`
*   **解鎖機制**：Act 1 完結，解鎖世界地圖的前往 Act 2 (霜風港) 節點，同時保留返回奧克哈芬的權限

### A. 聖物共鳴與北方的呼喚
主角帶著三枚碎片回到城鎮的轉職神殿。

*   **對話劇本**：
    ```
    賽恩：（看著主角手中的碎片，面露敬畏）
    「你做到了……你沒有被火印焚毀，反而穩定了它。這證明了艾爾德林當年的理論是正確的，你的體質是唯一的關鍵。但你看——」

    [賽恩將碎片放在神殿的月之井水面上。碎片上的符文突然亮起幽藍色的光芒，井水中倒映出北方被無盡冰川與暴風雪覆蓋的荒涼港口。]

    賽恩：
    「火印重組，使南方的地脈暫時回穩，但這也導致元素天平產生了傾斜。北方的『水之印記』正在承受雙倍的亂流壓力。那裡的冰川正在加速異常變化。你必須去北方的『霜風港』，尋找盲眼學者凱倫，他或許知道如何穩定北方的異動。」
    ```

### B. 正式晉升與跨區域委託
主角回到冒險者公會。

*   **對話劇本**：
    ```
    [公會大廳。諾亞看著主角走進來，臉上露出了欣慰的笑容，並從櫃檯下拿出一枚精緻的銀質徽章。]

    諾亞：
    「幹得漂亮，冒險者。火山熱浪退去了，鎮民們都安全了。公會總部已經確認了你解決葛倫、穩定地脈的功績。從今天起，你正式晉升為『青銅級冒險者』。」

    [諾亞將銀質徽章 and 一卷蓋有公會火漆的通行證遞給主角。]

    諾亞：
    「這是你的跨區域通行證。賽恩已經把北方的共鳴報告發給我了。我幫你申請了前往北方『霜風港支部』的協助委託。那邊的港口現在被異常暴風雪封鎖，正需要實力派的冒險者去幫忙。」

    諾亞：（指了指世界地圖）
    「霜風港的盲眼學者凱倫，曾是艾爾德林的學術夥伴。你想找尋導師的下落，他一定有線索。不過記住，奧克哈芬永遠是你的起點。不論你在北方走得多遠，隨時可以通過馬車或驛站回來。拉比的熔爐、米菈的合成屋、還有你的個人倉庫，隨時都為用敞開。出發吧，正式的冒險現在才開始！」

    [主角收起通行證與銀質徽章。雖然北方的風雪在世界地圖上亮起，但回望奧克哈芬溫暖的爐火，心中多了一份踏實。]

    【Act 1 完結 - 開啟 Act 2：冰印篇（霜風港）】
    ```
