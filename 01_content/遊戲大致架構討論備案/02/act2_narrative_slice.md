本文件為《Element Maze／元素迷宮》第二幕（霜風港篇）的**主線垂直切片劇本與城鎮規格書**。本設計確定了霜風港的視覺氛圍、全新的設施 NPC 名冊，以及推進主線 4 個核心任務的完整對話文本，確保玩法上的自由回溯與劇情的深度咬合。

## 1. 霜風港 (Galeport) 的樣貌與氛圍

*   **視覺風格**：半冰封的北境港口。碼頭的木質棧道覆蓋著厚厚的積雪與堅冰，港口的海水呈現冷冽的深黑色，漂浮著細碎的浮冰。
*   **環境特色**：城鎮上方的巨型古代蒸汽管道（由聖印教會控制）正向空中噴吐著滾燙但刺鼻的白煙，管道的鋪設強行割裂了平民居住的「下城區」與教會控制的「上城區」。
*   **背景音樂 (BGM) 氛圍**：以憂鬱的愛爾蘭風笛與緩慢的鋼琴為主旋律，夾雜著遠處海浪拍擊浮冰的低沉聲響，傳達出一種被風雪困住的孤立感與壓抑感。

## 3. 主線任務詳細劇本與對話 (Main Quests Scripts)

### 🎬 任務一：冰原的寒意 (The Glacial Chill)
*   **任務 ID**：`quest_galeport_arrival`
*   **目標**：抵達港口，登記委託，前往**霜凍裂隙**調配防凍藥膏。

#### 💬 對話：抵達公會與克莉絲汀登記
*   **場景**：霜風港公會。窗外寒風呼嘯，克莉絲汀正對著一堆結冰的帳本嘆氣。

```
[主角推門進來，遞上諾亞的介紹信與銀質徽章。]

克莉絲汀：（揉了揉太陽穴，看過信件後嘆了口氣）
「哦，奧克哈芬的新星。諾亞在信裡把你誇得像個救世主。但抱歉，孩子，霜風港現在不缺英雄，只缺煤炭和糧食。你看外面，航道被凍得結結實實，連隻海鷗都飛不出去。」

主角：
「我是來找學者凱倫的，順便調查地脈失衡。」

克莉絲汀：
「凱倫啊，他現在寄宿在海倫娜的『旅館』二樓客房裡。那老頭眼睛看不見，整天在房間裡摸著古代石板。你想調查遺跡？可以，但遺跡外圍現在的低溫能把鐵劍凍裂。先去西邊的『霜凍裂隙』活動活動筋骨，幫安妮帶點冰結晶和海蛇草回來吧。至少證明你不會在第一天就被凍死。」
```

#### 💬 對話：拜訪盲眼學者凱倫
*   **場景**：西側燈塔，四壁堆滿了古籍與石板。壁爐裡燃燒著微弱的火光，凱倫閉著雙眼，手撫摸著一塊古代石板。

```
凱倫：（耳朵動了動，轉過身微笑）
「陌生的腳步聲……沉穩而溫暖。你的體內沒有固定的元素雜質，你是艾爾德林的弟子吧？我能聞到他那枚『空白徽記』上的陳舊鐵銹味。」

主角：
「凱倫大師，我的導師曾在這裡做過什麼？」

凱倫：（神色變得凝重，手撫摸著雙眼的傷疤）
「艾爾德林當年試圖說服教會停止抽取遺跡的『水之精粹』。這座迷宮是個巨大的過濾器，強行抽乾水分會導致地脈的寒氣外溢，將整個港口封死。我的眼睛，就是當年試圖阻止他們過載設備時被強光灼傷的。
孩子，火印的重組已經驚動了北方的地脈。去遺跡吧，去揭開被大門封鎖的真相。」
```

### 🎬 任務二：背叛的騎士與鍋爐 (The Apostate Knight)
*   **任務 ID**：`quest_ruins_boiler`
*   **目標**：通關主地城階段 1（特提斯遺跡 Steps 1-18），擊敗小 Boss 路德維希，獲得「古代鍋爐核心」。

#### 💬 對話：遺跡大門前對決路德維希 (Steps 18)
*   **場景**：遺跡外圍入口。巨大的萬年玄冰將神殿鐵門封死。路德維希手持冰紋重盾，擋在冰封的蒸汽機前。

```
路德維希：（看著主角身上的防凍藥膏與徽章，巨盾重重砸地）
「止步，冒險者！這裡已經被聖印教會封鎖。任何人不得干擾『聖髓抽取程序』！」

主角：
「這項抽取正在毀掉下城區！平民們都在挨凍！」

路德維希：（眼神閃過痛苦，隨即被冰冷的職責取代）
「平民的生死在聖城的宏圖面前微不足道！聖城需要冰髓結晶來強化防禦……我曾誓死捍衛這項命令，即便我的良心在受折磨。
冒險者，如果你想打破這扇冰門，就先用你的武器擊碎我的誓言吧！」

[戰鬥開始：小首領 路德維希 (boss_ludwig)]
```

```
[路德維希單膝跪地，巨盾碎裂，口中吐出寒氣。他看著主角，釋懷地笑了。]

路德維希：
「你……很強。也許你真的能……阻止這場瘋狂。拿著這個（遞出古代鍋爐核心）……這是控制抽取鍋爐的鑰匙。
但大門已經被教會用萬年玄冰封印……一般的火焰無法融化它。去港口找奧丁……那老矮人知道怎麼製造能產生高溫蒸汽的破冰機……咳……」

[路德維希昏迷過去。主角取得關鍵道具：古代鍋爐核心。]
```

### 🎬 任務三：蒸汽破冰計畫 (The Steam Breaker)
*   **任務 ID**：`quest_steam_breaker`
*   **目標**：前往**雲海沈船**擊敗幽靈船長德雷克，取得「雷石」作為燃料，並與奧丁、克羅蒂亞修復破冰機。

#### 💬 對話：回城與奧丁、克羅蒂亞商討
*   **場景**：奧丁的鍛造工坊。

```
奧丁：（喝了一大口烈酒，猛拍桌子）
「你拿到了路德維希的鍋爐核心？！好！太好了！老子早就想把教會那台抽乾機給砸了。我可以用我的工坊改造成高壓蒸汽破冰機，一口氣融化遺跡的狗屁玄冰！」

克羅蒂亞：（靠在門框上，抽著煙斗）
「別高興得太早，奧丁。高壓蒸汽需要導電能極強的『雷石』作為瞬間點火的燃料。但現在唯一的雷石來源，都在那艘幾十年前沉在迷霧海灣的『雲海號』上。」

主角：
「我去拿回來。」

克羅蒂亞：
「痛快！但那艘船現在是鬼船，德雷克船長的亡靈還在那裡游蕩。如果你拿回雷石，順便幫酒館的老闆娘海倫娜帶回德雷克的隨身金幣吧，那女人等了她丈夫五十多功能了。這算我個人欠你的人情。」
```

#### 💬 對話：沈船深處對決幽靈船長德雷克 (次要地城 B Steps 18)
*   **場景**：雲海沈船傾斜的主甲板上。四周迷霧環繞，雷電在桅杆間游走。一個半透明的骷髏船長手持雙彎刀，阻擋在雷石寶箱前。

```
德雷克：（空洞的雙眼亮起雷光，聲音如風暴般嘶啞）
「風暴……將吞噬一切……誰也別想奪走我的船……搶奪雷石者……死！」

[戰鬥開始：小魔王 德雷克 (boss_drake)]

[戰後：擊敗德雷克，獲得雷石與德雷克的航海金幣。回到城鎮，將金幣交給海倫娜，海倫娜喜極而泣，贈予主角特殊裝備「潮汐護符」。]
```

### 🎬 任務四：冰縛之核的解封 (Unsealing the Ice)
*   **任務 ID**：`quest_unseal_water`
*   **目標**：啟動破冰機融冰，通關主地城階段 2（沉沒聖堂 Steps 19-36），擊敗關底 Boss 冰縛怨靈，回收水之印記。

#### 💬 劇情演出：破冰與開門
```
[主角將雷石交給奧丁。奧丁將雷石塞入蒸汽破冰機的爐心，破冰機爆發出震耳欲聾的轟鳴，噴射出上千度的高壓蒸汽。]

[滾燙的蒸汽衝擊在遺跡大門的萬年玄冰上，冰壁發出劇烈的碎裂聲，化為滔天洪水宣洩而出。遺跡的鐵門終於在蒸汽中緩緩開啟，露出了通往地底深處的黑漆通道。]
```

#### 💬 對話：聖堂核心對決冰縛怨靈 (Steps 36)
*   **場景**：沉沒聖堂祭壇。水流被強行凍結在半空中，形成奇異的冰之迴廊。巨大的靈體怨靈被粗大的鐵鏈捆綁在抽取管道上，發出痛苦的咆哮。

```
系統語音：（古代機械合成音）
「檢測到地脈流量異常……水元素過度流失……防衛程序強制超載……清除威脅……」

冰縛怨靈：（痛苦地怒吼，釋放出狂暴的冰風暴）
「滾出我的聖堂……無恥的竊取者……冰雪將掩埋一切罪行！」

[戰鬥開始：關底 Boss 冰縛怨靈 (boss_wraith)]
```
