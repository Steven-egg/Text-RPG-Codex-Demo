# GUI References

## 邊界

- 這裡的圖片是 reference / candidate，不是正式 runtime asset。
- 不代表已啟動正式 asset pipeline。
- 不代表圖片已可直接進遊戲。
- 不應被 `03_engine` 或 runtime 直接引用。
- 若未來要正式使用，需另行整理到正式 asset path，並補命名、來源、版本、授權 / 生成紀錄與替換策略。
