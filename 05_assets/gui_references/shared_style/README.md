# Shared GUI Style References

## Purpose

Cross-screen GUI / NPC / JRPG visual style references.

## Rules

- Reference only.
- Not runtime assets.
- Not a formal asset pipeline.
- Do not import these images from HTML/CSS/JS.
- Do not use these images as prototype backgrounds.
- Do not infer gameplay rules, item data, NPC identity, prices, stats, or UI text from these images.
- Dynamic text must remain render-layer output.
- Use only for visual style, NPC presence, layout mood, icon convention, and reference-alignment planning.
