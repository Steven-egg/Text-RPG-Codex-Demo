# Shared Style Reference Alignment Note

## Purpose

These files are cross-screen GUI / NPC / JRPG visual style references.

They are reference only, not runtime assets, not a formal asset pipeline, and not prototype backgrounds.

## Reference files

- `facility_shop_reference_v1.png` - shop mood, item-card layout, shopkeeper presence.
- `facility_workshop_reference_v1.png` - workshop mood, equipment panel language, craftsman presence.
- `facility_magic_shop_reference_v1_01.png` - magic shop mood, spellbook grid, arcane panel color.
- `facility_magic_shop_reference_v1_02.png` - magic shop mood, NPC presence, arcane interior.
- `facility_synthesis_reference_v1.png` - synthesis mood, material requirement panel, alchemy presence.
- `facility_academy_reference_v1.png` - academy mood, study room presence, guidance-style menu.
- `facility_inn_reference_v1.png` - inn mood, rest/tavern presence, warm facility framing.
- `facility_guild_reference_v1.png` - guild mood, quest board presence, support-service framing.

## Allowed usage

- Visual style alignment.
- NPC presence reference.
- Facility screen mood.
- UI material / frame / panel language.
- Future Antigravity prototype brief reference.

## Forbidden inference

- Do not infer gameplay rules.
- Do not infer item data.
- Do not infer NPC identity.
- Do not infer prices.
- Do not infer stats.
- Do not infer UI text.
- Do not infer runtime behavior.
- Do not use these images as prototype backgrounds.
- Do not import these images directly into HTML / CSS / JS.
